# DataMind 前端重设计

用户选择：专业 BI 工作台，浅色、清晰、数据优先。

## 实际参考

- Metabase：访问 https://www.metabase.com/ 、https://www.metabase.com/docs/latest/dashboards/introduction 并放大查看 Interactive dashboard 电商示例。借鉴主次图表、明确日期范围、业务说明紧邻数据的布局。
- Lightdash：访问 https://www.lightdash.com/ 并进入公开 Demo https://demo.lightdash.com/projects/saas-demo/home 和 Plumly Sales 看板。借鉴固定工作区导航、图表上下文、分析与 Ask AI 的衔接。
- Plausible：访问 https://plausible.io/plausible.io，观察到紧凑筛选工具栏和按主题切换的布局；本次公开数据图表未完成加载，不将其数据或图形作为验证依据。

## 视觉方案

- 画布 `#F5F7FB`，面板 `#FFFFFF`，正文 `#18243B`，次级文字 `#64748B`，分析蓝 `#3568E8`，辅助青绿 `#169E91`。
- 字体：Bahnschrift 用于品牌和数值，Microsoft YaHei / Segoe UI 用于中文正文和控件；正文 14px，标题 26px，核心数值 28px。数字采用等宽数字特性，明确币种。
- 布局：左侧固定工作区导航，右侧上方标题和数据范围；指标在首屏，主趋势图与品类贡献并列；卖家表与可核对的数据摘要置于下一排。手机端改为顶部横向导航。
- 交互：真实年份筛选和趋势指标切换、全量排行检索、上下文问数入口、对话和数据明细；每个可见操作都连接到可用功能。

```text
工作区导航 | 面包屑 / 数据读取状态
          | 经营总览                         数据覆盖 / 刷新
          | GMV       订单数       客户数       客单价
          | 交易趋势（指标切换、年份）         品类贡献
          | 卖家排行                         数据摘要 / 问数
```

## 对方案的复核

删除旧版大幅宣传区、同心圆装饰和营销式文案，将注意力留给真实数据。蓝色仅用于选中项与主数据序列；不使用虚构涨幅、在线状态、实时数据或不可用按钮。全周期指标不随局部年份筛选变化，图表旁明确说明范围。聊天页保留相同导航并保留切页前的会话状态。

## 完成与验收

- `npm test`：5 项通过，覆盖金额/数字、首末月边界、受限历史、年份筛选与零订单客单价、排行多字段检索。
- `npm run build`：成功。主 JS 约 1,486 kB，gzip 约 492 kB，仍有 chunk 大于 500 kB 的提示；本次聚焦界面重设计，未做懒加载拆包。
- 浏览器实测 1280/1440px 桌面、1024/768px 中等屏、390px 手机和 320px 边界；修复了极窄屏导航与长 GMV 卡片溢出，整页无横向溢出，表格在容器内横向滚动。
- 实测 2017 年趋势 12 条记录、订单数切换、品类 health 检索、卖家多字段检索、口径弹窗和刷新。
- 实际后端问数：health_beauty 品类 GMV 1,437,665.78 BRL / 8,800 单；月度趋势返回 25 行，图表/分页/SQL 展开正常；退款率给出未支持提示。切页会话保留和新对话已验证。
- 最终页面控制台未发现 warn/error。后端、ETL、数据库与凭据未改动。
